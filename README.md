# chrome-plugin-forceJump

## 适用范围
- Chrome / Edge（Chromium 内核浏览器）

## 适用网站
- 掘金
- 简书
- CSDN
- 知乎

## 简介
在阅读文章时，部分站点会将外链改写成安全跳转页。  
这个插件会把跳转链接恢复成真实目标链接，点击后直接打开目标地址。

## 当前能力
- 支持识别常见跳转域名与参数（如 `target`、`to`、`t`）
- 页面首次加载时自动处理
- 页面后续动态渲染内容也会持续处理（SPA 场景）
- 仅改写链接地址，不再修改页面正文内容
- 支持可配置开关（全局开关、按站点开关、调试日志开关）

## 安装方法
1. 下载项目代码并解压
2. 打开 `chrome://extensions/`
3. 开启右上角 `开发者模式`
4. 点击左上角 `加载已解压的扩展程序`
5. 选择当前项目目录并加载

## Manifest 版本说明
项目当前已经是 `manifest_version: 3`，无需再从 v2 升级。

## 配置开关
1. 打开 `chrome://extensions/`
2. 找到 `forceJump`，点击 `详情`
3. 进入 `扩展程序选项`（或右键插件图标 -> 选项）

可设置项：
- 是否全局启用
- 是否在 CSDN / 掘金 / 简书 / 知乎启用
- 是否输出调试日志

说明：修改设置后，建议刷新已打开的网页再验证效果。
